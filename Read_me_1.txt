Hello!

This project, built in Godot 4.7.2, is an app that simulates the result of opening a Play Booster Pack from the Aetherdrift set from Magic The Gathering.

It is set up so that other sets may easily be added via new dictionaries.

This can be used to show how many packs you would have to open to receive a specific card. It can also be used as a tool to host a Magic The Gathering draft without actually purchasing the booster packs, via deck-testers like Archidekt's or Manabox's.
